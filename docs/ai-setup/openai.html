OpenAI

Hosted, needs your own OpenAI API key. Requests use strict JSON Schema mode so the model's output always matches BerryStudio's Pattern Spec exactly.

Endpointhttps://api.openai.com/v1/chat/completions
Needs a keyYes
Structured outputresponse_format: {type: "json_schema"}, validated against BerryStudio's own schema before it's ever drafted

Setup

  1. Get an API key at platform.openai.com.
  2. In BerryStudio: Settings → AI Provider → choose OpenAI.
  3. Paste your key, fetch or type a model name, then Test Connection.

Also used for the AI Fashion Billboard image-generation feature (Settings → AI Provider → Image generation), if you want AI-generated lookbook imagery alongside your patterns.

Called directly from the browser — OpenAI's API is CORS-permitted for this, no local server or extra header needed.

الإعداد

  1. احصل على مفتاح API من platform.openai.com.
  2. في BerryStudio: الإعدادات ← مزوّد الذكاء الاصطناعي ← اختر OpenAI.
  3. الصق مفتاحك، اجلب أو اكتب اسم نموذج، ثم Test Connection.

يُستخدم أيضًا لميزة إعلان الأزياء بالذكاء الاصطناعي (الإعدادات ← مزوّد الذكاء الاصطناعي ← توليد الصور)، إن رغبت في صور دعائية مولّدة بالذكاء الاصطناعي إلى جانب أنماطك.

يُستدعى مباشرة من المتصفح — واجهة OpenAI مسموح بها عبر CORS لذلك، دون الحاجة لخادم محلي أو ترويسة إضافية.
