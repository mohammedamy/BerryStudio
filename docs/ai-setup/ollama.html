Ollama (local)

Runs entirely on your own machine. No API key, no data ever leaves your computer. Supports vision with a vision-capable model (e.g. llava, llama3.2-vision, qwen2-vl).

Endpointhttp://localhost:11434
Needs a keyNo
Model listFetched live from Ollama's own /api/tags — only models you've already pulled show up

Setup

  1. Install Ollama from ollama.com and pull a model, e.g. ollama pull llama3.2-vision.
  2. Start Ollama with browser access enabled — by default it blocks requests from a web page origin. Run: OLLAMA_ORIGINS="https://mohammedamy.github.io,http://localhost:8791" ollama serve Adjust the second origin to whatever local port you're actually serving BerryStudio from during development.
  3. In BerryStudio: Settings → AI Provider → choose Ollama (local). Click Fetch Models to list what you've pulled.
  4. Test Connection — if it fails with a CORS-shaped error, double-check step 2's OLLAMA_ORIGINS value matches the exact origin BerryStudio is running from.

Ollama (محلي)

يعمل بالكامل على جهازك الخاص. بلا مفتاح API، ولا تغادر أي بيانات جهازك أبدًا. يدعم الرؤية مع نموذج يدعم الرؤية (مثل llava، llama3.2-vision، qwen2-vl).

نقطة النهايةhttp://localhost:11434
يحتاج مفتاحًالا
قائمة النماذجتُجلب مباشرة من /api/tags الخاصة بـOllama — تظهر فقط النماذج التي سبق تنزيلها

الإعداد

  1. ثبّت Ollama من ollama.com وحمّل نموذجًا، مثل ollama pull llama3.2-vision.
  2. شغّل Ollama مع تفعيل الوصول من المتصفح — فهو يمنع طلبات صفحة الويب افتراضيًا. نفّذ: OLLAMA_ORIGINS="https://mohammedamy.github.io,http://localhost:8791" ollama serve عدّل العنوان الثاني ليطابق المنفذ المحلي الذي تشغّل BerryStudio عليه فعليًا أثناء التطوير.
  3. في BerryStudio: الإعدادات ← مزوّد الذكاء الاصطناعي ← اختر Ollama (محلي). اضغط Fetch Models لعرض ما حمّلته.
  4. Test Connection — إذا فشل بخطأ يشبه CORS، تحقق من أن قيمة OLLAMA_ORIGINS في الخطوة 2 تطابق العنوان الفعلي الذي يعمل عليه BerryStudio تمامًا.
