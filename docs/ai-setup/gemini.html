Google Gemini

Hosted, needs your own Google AI Studio API key.

Endpointhttps://generativelanguage.googleapis.com/v1beta/models/<model>:generateContent?key=<your key>
Needs a keyYes — sent as a URL query parameter, per Google's own API design (BerryStudio never logs or exports the full URL with the key attached)
Structured outputGemini's responseSchema field, set to BerryStudio's Pattern Spec schema

Setup

  1. Get an API key at aistudio.google.com.
  2. In BerryStudio: Settings → AI Provider → choose Google Gemini.
  3. Paste your key, pick a model (e.g. a Gemini 2.x/3.x model that supports vision if you plan to upload photos), then Test Connection.

Also usable for image generation (AI Fashion Billboard) if your key has access to a Gemini image model.

مستضاف، يحتاج مفتاح API خاص بك من Google AI Studio.

نقطة النهايةhttps://generativelanguage.googleapis.com/v1beta/models/<model>:generateContent?key=<مفتاحك>
يحتاج مفتاحًانعم — يُرسَل كمعامل استعلام في الرابط، وفق تصميم واجهة Google نفسها (BerryStudio لا يسجّل أو يصدّر الرابط الكامل مع المفتاح أبدًا)

الإعداد

  1. احصل على مفتاح API من aistudio.google.com.
  2. في BerryStudio: الإعدادات ← مزوّد الذكاء الاصطناعي ← اختر Google Gemini.
  3. الصق مفتاحك، اختر نموذجًا (مثل نموذج Gemini 2.x/3.x يدعم الرؤية إن كنت تنوي رفع صور)، ثم Test Connection.

قابل للاستخدام أيضًا لتوليد الصور (إعلان الأزياء بالذكاء الاصطناعي) إذا كان مفتاحك يملك صلاحية الوصول لنموذج صور من Gemini.
