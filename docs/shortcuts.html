Canvas & selection

KeyAction
[ / ]Cycle the selected piece backward / forward — not Tab, so Tab keeps moving focus between toolbar and panel controls as usual
Arrow keysNudge the selected piece by 1 cm
Shift+ArrowNudge the selected piece by 0.1 cm (fine adjustment)
Delete / BackspaceDelete the selected piece

Global

KeyAction
Ctrl/⌘+ZUndo
Ctrl/⌘+Shift+Z (or Ctrl+Y)Redo
Ctrl/⌘+KOpen the command palette
EscClose the topmost modal, menu, or text editor
Canvas selection/nudge/delete/cycle shortcuts (WP-17) currently operate on whole pattern pieces. Construction points, lines, arcs, and circles are edited by dragging with the mouse today — keyboard-only editing of individual construction points is a documented gap, not yet built.
