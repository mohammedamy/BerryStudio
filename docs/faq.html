FAQ

Does BerryStudio require an account or internet connection?

Core drafting runs locally in your browser. Some features currently require sign-in and trial access. Cloud AI needs a configured provider and an internet connection. Offline availability depends on cached assets and the feature used; it is not guaranteed for every workflow.

Where is my data stored?

In your browser's own local storage, on your own device. Save Project (.json) lets you export a full, lossless copy any time — the same file re-imports exactly as it was.

Are the Fancy Collection's 64 elaborate designs couture-accurate, or just stylised?

They're real, gradable, exportable multi-piece patterns with genuinely curved (bezier-sampled) seams — princess seams, godets, capes, tiers, lapels, hoods. Their proportions come from heuristic ratios of your body measurements, in the same style as the app's hand-crafted base patterns, not from couture drafting-book formulas. Treat them as realistic design references to grade and export, not seam-allowance-exact sewing patterns ready for a cutting table without review.

How accurate is "Check Pattern"?

Geometry checks inspect the piece outline, grainline, seam allowance, and fold symmetry. Cross-piece checks use explicit seam roles where available and label name-based fallback matches as heuristic. Missing pairing or measurement metadata limits what can be verified. A passing report is a geometry check, not evidence that a garment has been sewn and fitted.

Does "Full nest" (Create Marker) guarantee the tightest possible fabric layout?

No nesting algorithm — commercial or open-source — guarantees a provably optimal layout in general (true 2D nesting is NP-hard); BerryStudio's Full nest runs a real bottom-left-fill + simulated-annealing search over genuine polygon overlap for a good, practical result within its time budget, reporting real utilisation. "Fast preview" trades that for an instant bounding-box estimate.

Can I use BerryStudio's local automation API for batch work?

Yes — window.BerryStudio exposes generate, grade, nest, export, and validate, callable from the browser console or an injected script against the currently loaded pattern. See the main README's Automation API section for runnable examples.

What should I do when Check Pattern reports a warning or failure?

Inspect the named piece and check before cutting. Reports depend on the current geometry and available metadata; grading and edits can change the result. Resolve failures and review warnings with a pattern maker. Do not assume an unverified check has passed.

الأسئلة الشائعة

هل يتطلّب BerryStudio حسابًا أو اتصالًا بالإنترنت؟

يعمل الرسم الأساسي محليًا في متصفحك. تتطلب بعض الميزات حاليًا تسجيل الدخول والوصول التجريبي. يحتاج الذكاء الاصطناعي السحابي إلى إعداد مزوّد واتصال بالإنترنت. يعتمد العمل دون اتصال على الملفات المخزنة مؤقتًا والميزة المستخدمة، ولا يُضمن لكل مسارات العمل.

أين تُخزَّن بياناتي؟

في التخزين المحلي الخاص بمتصفحك، على جهازك أنت. يتيح لك "حفظ المشروع" (.json) تصدير نسخة كاملة وبلا فقدان في أي وقت — نفس الملف يُستورد بالضبط كما كان.

هل تصاميم مجموعة Fancy الـ64 المتقنة دقيقة بمعايير الأزياء الراقية، أم مجرد تصاميم شكلية؟

هي أنماط حقيقية متعددة القطع، قابلة للتدريج والتصدير، بخياطات منحنية فعليًا (مُستخرجة من منحنيات بيزيه) — خياطات أميرة، قطع كسرات (godets)، عباءات، طبقات، ياقات، غطاء رأس. تأتي نسبها من نسب استدلالية لقياسات جسمك، بنفس أسلوب الأنماط الأساسية اليدوية في التطبيق، وليس من معادلات كتب الخياطة الراقية. تعامل معها كمراجع تصميم واقعية للتدريج والتصدير، وليست أنماط خياطة دقيقة بسماح الحياكة جاهزة لطاولة القص دون مراجعة.

ما مدى دقة "فحص الباترون"؟

تفحص الاختبارات الهندسية حدود القطعة واتجاه القماش وسماح الخياطة وتماثل الطية. تستخدم الفحوصات بين القطع أدوار الخياطة الصريحة حيث تتوفر، وتُصنّف المطابقة الاحتياطية بالأسماء بأنها استدلالية. تحدّ بيانات الإقران أو القياسات المفقودة مما يمكن التحقق منه. نجاح الفحص الهندسي لا يعني أن الثوب خِيط واختُبر على الجسم.

هل "التعشيق الكامل" (إنشاء تخطيط القص) يضمن أضيق تخطيط قماش ممكن؟

لا توجد خوارزمية تعشيق — تجارية أو مفتوحة المصدر — تضمن تخطيطًا مثاليًا مُثبَتًا رياضيًا بشكل عام (تعشيق ثنائي الأبعاد الحقيقي مسألة NP-صعبة)؛ يشغّل "التعشيق الكامل" في BerryStudio بحثًا حقيقيًا بملء من أسفل اليسار مع محاكاة التلدين فوق تداخل مضلعات فعلي، لنتيجة جيدة وعملية ضمن حدود وقته، ويُبلغ عن نسبة استخدام حقيقية. "المعاينة السريعة" تضحّي بذلك مقابل تقدير فوري بالمربعات المحيطة.

هل يمكنني استخدام واجهة الأتمتة المحلية في BerryStudio لعمل دفعي؟

نعم — يوفّر window.BerryStudio الدوال generate وgrade وnest وexport وvalidate، القابلة للاستدعاء من طرفية المتصفح أو من كود مُحقَن على الباترون المحمَّل حاليًا. راجع قسم "Automation API" في README الرئيسي لأمثلة قابلة للتشغيل.

ماذا أفعل عندما يظهر تنبيه أو فشل في فحص الباترون؟

راجع القطعة والفحص المذكورين قبل القص. تعتمد النتائج على الهندسة الحالية والبيانات المتاحة، وقد تتغير بعد التدريج أو التعديل. أصلح حالات الفشل وراجع التنبيهات مع صانع باترونات. لا تعتبر الفحص غير المتحقق منه ناجحًا.
