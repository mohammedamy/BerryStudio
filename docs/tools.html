Tool reference

Every tool on the stage toolbar, plus the drafting, grading, and construction features layered on top.

Vector drafting tools

ToolWhat it does
SelectClick pieces to select, drag to move. Shift-click for multi-select.
LassoDrag a freehand loop around several pieces to select them all at once — Shift-drag to add to the current selection. Drag any one of them to move the whole group together; Delete removes the whole group.
Pen (Bézier)Draw precise Bézier curves. Click for corner points, drag for smooth handles.
LineDrag to draw a straight sketch line — a plain freehand mark, not linked to any point. For a line that stays attached to points as you move them, use the associative Construction Line tool below instead. Hold Shift while dragging to constrain the angle to vertical, horizontal, or 45°.
ArcClick start → end → bulge to draw a curved sketch mark — freehand, not linked to points. For a curved arc that can become a real pattern-piece edge, draw a Construction Arc between two points instead, then use Create Pattern Piece.
FreehandSketch freely with the mouse — for loose creative drafting.
Filled ShapeClick to add points for a closed, filled shape (e.g. a pocket or trim). Click near the start point, or double-click, to close it.
SymmetryMirror everything across a centre axis — for bodices and other fold-symmetric pieces.
KnifeSlit or split a pattern piece to add darts or style lines.
MoveNudge selected geometry with pixel precision.
RotateRotate a piece around a pivot — e.g. for rotating darts.
ScaleScale a piece up or down proportionally.
MeasureMeasure any distance on the pattern, in cm or inches.
Seam AllowanceAdd an automatic seam allowance around the cutting edge — uniform, or per-edge with miter/round/bevel corner joins (WP-14).
NotchPlace alignment notches so pieces match when sewing.
Add PointClick any piece's outline edge to insert a new point there, splitting that edge in two.
Curve EdgeDrag along any piece's edge to bow it into a real curved seam. Drag an already-curved edge again to reshape it, or click it (no drag) to revert it back to straight. Doesn't work on a piece's closing edge (the segment back to its first point).
GrainlineSet the grainline so fabric is cut in the right direction.
TextClick the canvas to place a formatted label; click existing text to edit it. Drag with Select to move.

Editing an outline point-by-point

Beyond the drafting tools above, any piece's outline can be reshaped point-by-point directly:

  • Select a single point — with the Select tool and the piece already selected, click one of its own point handles (not the piece's resize corners) to select just that vertex, shown larger and highlighted. Delete/Backspace removes only that point (refused below 3 points, so a piece can never collapse into a non-polygon). Corner points specifically are offset a few pixels outward from the piece's resize handle, so the two no longer fight for the same click.
  • Set a point's exact coordinates, or name it — open Edit Outline Points & Edges from a piece's properties (Layers pane → the ⋯ button on a piece), which lists every outline point with editable X/Y (cm) and an optional name. Give two points — on the same piece or two different pieces — the identical name, and BerryStudio treats them as a match: the printed Sewing Instructions guide (Project menu) generates a real step telling you to bring those two named points together and seam them, the same way a notch does but for a specific point rather than a whole edge.
  • Mark an edge as a closing edge — in the same Edit Outline Points & Edges panel, any edge can be flagged as a closing edge: left open, unsewn, for the garment's own closure (a zip, button placket, or hook-and-eye) instead of being seamed shut like every other edge. It's drawn on the 2D canvas as a thick amber dashed line so it's visually obvious, and the Sewing Guide explicitly calls out which edge(s) to leave open, with a short legend explaining the convention.

Associative construction tools

A real, live-linked CAD layer beneath the vector tools: Point, Construction Line, Construction Arc, and Circle reference each other by ID, not frozen coordinates — dragging a point (or giving it a formula that references a Variable or a body measurement) updates everything built on it, including after grading. Hold Shift while dragging a Construction Line (or its endpoint) to constrain the angle to vertical, horizontal, or 45° — the same convention the plain Line tool uses. Variables are named formulas reusable in any point's X/Y. A background trace image with two-point calibration lets you draft over a reference photo at the correct real-world scale. Create Pattern Piece promotes a closed loop of points into a real, exportable piece — a one-time snapshot, not a live link: editing the original points afterwards no longer reshapes the promoted piece.

Grading & nesting

FeatureWhat it does
Auto Grade (Size pane)Proportional grading across XXS→6XL, Intl/Egyptian/Saudi standards, Kids ages, and fully custom measurements — live, no re-generation.
Grade Rules (Size pane, WP-13)Per-piece, per-outline-point dx/dy-per-size-step overrides on top of the proportional grade, for industrial-style control over exactly how a piece grows between sizes. Import/export as JSON. A point with no authored rule keeps grading through the normal proportional formula, unchanged.
Grade Nest preview (WP-13)Overlays every size of one piece at a shared alignment point — the standard visual professional patternmakers use to sanity-check a grade.
Create MarkerNest pattern pieces onto a virtual fabric roll. Fast preview is instant bounding-box packing; Full nest (WP-11) runs a real polygon-interlocking search in a background Web Worker, with a genuine cancelable Stop button, and reports real fabric utilisation and yardage.

Dart manipulation & drafting upgrades (WP-14)

FeatureWhat it does
Edit Darts (Layers → piece properties)Pivot rotates a dart's legs around its apex while preserving the intake angle; Slash & Spread widens a dart by a fixed amount at the apex.
Walk the Seam (Export pane)Pick a declared seam pair and drag one slider to check that both edges match at every position along their length, not just at the ends — the visual, interactive front-end to the same arc-length math Check Pattern's seam-length-parity check uses.
Waist / Sleeve Cap Fullness (Quick Draft, skirts & sleeved kinds)Pick a real technique — Pleat, Gather, or Tuck — at Light or Full intensity; each adds real, computed extra fabric width to the panel or sleeve cap by its own formula, not a cosmetic label. "None" (the default) leaves the piece unchanged.

Export & validation

FeatureWhat it does
Check Pattern (⌘K)8 patternmaking checks — closed outline, self-intersection, grainline, seam-allowance validity, cut-on-fold symmetry, seam-length parity, notch alignment, ease — with pass/warn/fail chips.
ExportSVG, DXF (real AAMA/ASTM D6673 layers), HPGL (genuine plotter cut-lines), PNG/JPEG (selectable DPI), PDF (single-page or tiled home-printing with registration marks and an assembly map), AI (PDF + %AI header).
Pattern SummaryA one-page bilingual print sheet: size table, a dimensioned diagram per piece, and construction notes.
Tech PackPiece list with EN/AR names and the full custom-measurement set for the current grade.
Sewing InstructionsA real, ordered construction sequence generated from the loaded pattern's own declared piece roles — prep/interfacing → darts → yoke → shoulder seams → collar → sleeves → pockets → zip/placket → waistband → cuffs → buttons → lining → hem → press — plus, if the pattern uses them, a step per matched named point and per closing edge (see "Editing an outline point-by-point" above), with a short legend explaining both. A step only appears when the pattern actually has that construction.
Fit Chart (WP-40)A per-size measurement spec sheet with a live-editable ± tolerance per point, computed by the same grading engine as Auto Grade for every size in the current standard (or every age, in Kids mode).
Bill of MaterialsAn itemized materials list (fabric, lining, interfacing, zip, buttons, thread, labels) derived from the pattern's real declared piece roles, plus a cutting list and a fabric consumption + cost estimate (USD/SAR/EGP).

Other panels

Layers — add/delete/rename pieces (EN+AR), per-layer colour and fill opacity, lock/unlock, show/hide. Object Browser — a read-only list of every point/line/arc/circle/piece/text with a name filter; click a row to jump the canvas to it. Snapshot — freeze the pattern's current state as a translucent ghost layer to compare later edits against. 3D Preview / 3D Cloth Lab — see the 3D troubleshooting page.

تعديل الحدود الخارجية نقطة بنقطة

إضافة لأدوات الرسم أعلاه، يمكن إعادة تشكيل حدود أي قطعة نقطة بنقطة مباشرة:

  • تحديد نقطة واحدة — بأداة التحديد والقطعة محددة بالفعل، اضغط على أحد مقابض نقاطها (وليس زوايا تكبير القطعة) لتحديد تلك النقطة فقط، وتظهر أكبر ومميّزة. Delete/Backspace يحذف تلك النقطة فقط (يُرفض تحت 3 نقاط، حتى لا تنهار القطعة إلى شكل غير مضلّع). نقاط الزوايا تحديدًا مُبعَدة ببضعة بكسلات إلى الخارج عن مقبض تكبير القطعة، حتى لا يتنافسا على نفس الضغطة.
  • تحديد إحداثيات نقطة بدقة، أو تسميتها — افتح تعديل نقاط وحواف الحد الخارجي من خصائص القطعة (لوحة الطبقات ← زر ⋯ على القطعة)، وتعرض كل نقطة في الحدود الخارجية مع X/Y (سم) قابلين للتعديل واسم اختياري. أعطِ نقطتين — على نفس القطعة أو على قطعتين مختلفتين — نفس الاسم، ويتعامل معهما BerryStudio كتطابق: يُنشئ دليل تعليمات الحياكة المطبوع (قائمة المشروع) خطوة حقيقية تطلب توصيل هاتين النقطتين المسمّاتين وخياطتهما، بنفس طريقة علامة التطابق لكن لنقطة محددة بدلاً من حافة كاملة.
  • تعليم حافة كحافة إغلاق — في نفس لوحة تعديل نقاط وحواف الحد الخارجي، يمكن تعليم أي حافة كحافة إغلاق: تُترك مفتوحة، دون حياكة، لإغلاق الملابس نفسه (سحاب، حاشية أزرار، أو كبك) بدلاً من خياطتها مثل بقية الحواف. تُرسم على اللوحة ثنائية الأبعاد كخط متقطع سميك كهرماني اللون ليكون واضحًا بصريًا، ويُشير دليل تعليمات الحياكة صراحةً إلى أي حافة (حواف) يجب تركها مفتوحة، مع شرح موجز لهذا الاصطلاح.

أدوات الإنشاء الترابطية

طبقة CAD حقيقية ومرتبطة تحت أدوات المتجهات: نقطة وخط إنشاء وقوس إنشاء ودائرة تشير إلى بعضها بمعرّفات وليس بإحداثيات ثابتة — سحب نقطة (أو ربطها بمعادلة تشير إلى متغيّر أو قياس جسم) يحدّث كل ما بُني عليها، بما في ذلك بعد التدريج. اضغط مع الاستمرار على Shift أثناء سحب خط إنشاء (أو أحد طرفيه) لتقييد الزاوية إلى رأسية أو أفقية أو ٤٥ درجة — نفس اصطلاح أداة الخط العادية. المتغيّرات هي معادلات مسمّاة قابلة لإعادة الاستخدام في إحداثيات X/Y لأي نقطة. تتيح صورة مرجعية خلفية مع معايرة بنقطتين الرسم فوق صورة مرجعية بالمقياس الحقيقي الصحيح. إنشاء قطعة باترون يرقّي حلقة نقاط مغلقة إلى قطعة حقيقية قابلة للتصدير — لقطة لمرة واحدة، وليست رابطًا حيًّا: تعديل النقاط الأصلية لاحقًا لا يغيّر شكل القطعة المُرقّاة.

لوحات أخرى

الطبقات — إضافة/حذف/إعادة تسمية القطع (بالإنجليزية والعربية)، لون وشفافية تعبئة لكل طبقة، قفل/فتح، إظهار/إخفاء. متصفح العناصر — قائمة للقراءة فقط بكل نقطة/خط/قوس/دائرة/قطعة/نص مع فلتر بالاسم؛ اضغط على صف للقفز إليه في اللوحة. لقطة (Snapshot) — جمّد حالة الباترون الحالية كطبقة شبح شفافة لمقارنة التعديلات اللاحقة بها. المعاينة ثلاثية الأبعاد / 3D Cloth Lab — راجع صفحة حل مشاكل العرض ثلاثي الأبعاد.
